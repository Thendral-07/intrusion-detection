Chicago 95

A retro desktop OS design system rebuilt for the modern web. Beveled silver chrome, navy title bars, and pixel-tight typography evoke the chunky charm of mid-90s computing.

Design system preview

Concept

Chicago 95 reinterprets the classic operating-system look as a reusable component language. Every surface is a window: 2-pixel outset bevels carve light and shadow into silver panels, navy headers anchor each frame, and the iconic teal desktop ties the screen together. Type stays small, monospace where it matters, and icons stay crisp and outlined so the whole system feels like a workstation booting up.
